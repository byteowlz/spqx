# ADR 0003: Keep ICL context separate from editable speaker geometry

Accepted for full-ICL persistence. Human replay retained accent; subsequent fixed-context speaker editing did not provide useful audible control in the tested0.6B route. See `docs/frozen-icl.md`. The user heard accent loss when an English reference was reduced to a native Qwen0.6B speaker vector. This does not prove that vectors contain no accent information, but disproves equivalent accent preservation for that tested vector-only route. Replacing the vector-only format or silently reconstructing missing context would break selected voices.

Keep `FrozenConditioning` v1 and fitted PCA bank bytes/semantics unchanged. Add distinct `FrozenIcl` data: the existing complete speaker vector plus an independently scoped/checksummed ICL reference context containing exact original reference text and RVQ codes. PCA may replace the speaker vector only within the identical scope; it never projects/interpolates discrete codec codes or silently changes their text. A source-audio hash is provenance, not an authenticity or transcript-accuracy claim. Source WAV remains an optional archive, never a frozen-ICL runtime input.

The first supported context format is deliberately closed: the qualified Qwen12Hz F32 codec SHA256 `b16b95557c7c7340a121757bd6855b9609e1cf4ad3fad0778b89393293ae5f3d`,16 codebooks,2048 entries, native `[K,T]` row-major/T-fastest int32 layout,1–512 frames. Other codecs/formats fail explicitly until separately inspected/qualified. Bind existing ABI6 `qt_num_codebooks` and compare the loaded model before passing owned arrays; do not change the native pin, ABI, worker protocol or implement a tensor engine. Existing native reference extraction already owns both latent arrays. MLX frozen loading remains unsupported.

Saved audition bundle v2 adds optional `icl_context`, while v1 has none and serializes exactly as before. The audition WAV/text may be German while the ICL source text/codes are English; these are different performances and must not be conflated. Registry profiles retain the existing sidecar sentinel tag and add a v2 tag: old strict readers must attempt the sidecar and reject its unknown v2 data, not fall back to cloning the audition WAV. No voqx schema fork or automatic registration.

CLI extraction explicitly opts into full ICL; Preview can load it directly or combine its fixed context with a same-scope frozen/PCA speaker vector. Native tests must establish original-reference vs persisted-context replay after source paths are absent, fresh-process vector/code/text custody, scope/layout/range/hash failures, cancellation/EOS/recovery and unchanged vector-only behavior. Human listening must separately establish accent/character preservation before nonzero PCA experiments and the100-voice rating bank. No semantic accent knob or neural training is implied; live Lab changes are deferred until this seam is qualified.
